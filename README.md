# Oğuzhan Berke Özdil personal research website

This is the English, single-page React and Vite research profile for Oğuzhan Berke Özdil. The production build is published through GitHub Pages.

## Local preview

```sh
npm install
npm run dev
```

Use `npm run check` before review. It validates the copy, runs TypeScript and creates the production build in `dist/`.

## Content and assets

- Editable text, research facts, project data and links are in `src/content/site.ts`.
- Page sections are split into focused components in `src/components/`.
- The professional portrait was resized from the user's CV photo without altering the person, clothing or background.
- VIBRONAV and UltraClear images are optimized local copies from the user's public project repository.
- The thesis-directions image is a conceptual editorial graphic generated for this site. It does not represent measured data.
- The academic-path background is a decorative editorial texture, not experimental evidence.
- Potential BSc and MSc thesis directions are maintained in `src/content/site.ts`. They are not confirmed openings.
- Private PhD documents, raw datasets, unpublished manuscripts and administrative files are not included.

## Publication checklist

Before each public update, run `npm run check`, review the responsive layouts, and confirm that research status, publication links and contact details remain current.
